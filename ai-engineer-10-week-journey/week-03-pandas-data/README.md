# Week 03 — Pandas and Data Analysis

**Planned dates:** 26 October–1 November 2026  
**Status:** Not started

## Goal
Load, inspect, clean, analyze, and communicate findings from a real dataset.

## Learning objectives
- [ ] Load a CSV into a DataFrame and inspect quality/schema.
- [ ] Handle missing values, duplicates, and types with reasons.
- [ ] Filter, sort, group, and aggregate data.
- [ ] Answer questions using tables or plots.

## Core concepts
- Series/DataFrames
- read_csv, head, info, describe, shape
- Filters, sorting, groupby, aggregation
- Missing values, duplicates, type conversion
- Basic plots and exploratory analysis
- Notebook reproducibility and dataset provenance

## Daily plan
1. Choose a modest public dataset and record its source and terms.
2. Load the data; inspect dimensions, types, missing values, and summaries.
3. Practice filters, sorting, groupby, aggregation, and derived columns.
4. Clean missing values/types and explain each major choice.
5. Answer three questions and make clear charts/tables.
6. Restart the kernel and run the notebook top to bottom.
7. Summarize findings, limitations, and data provenance.

## Weekly build
Analyze one public, appropriately licensed dataset in a notebook and answer at least three clear questions with data-backed evidence.

## Testing and evaluation
- [ ] Notebook runs from a fresh kernel in order.
