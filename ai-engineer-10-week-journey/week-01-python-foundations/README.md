# Week 01 — Python Foundations

**Planned dates:** 12–18 October 2026  
**Status:** Not started

## Goal
Write small, readable Python programs using variables, control flow, functions, and input validation.

## Learning objectives
- [ ] Use strings, numbers, booleans, and type conversion appropriately.
- [ ] Implement conditionals and loops.
- [ ] Write functions with parameters and return values.
- [ ] Validate input and debug common runtime errors.

## Core concepts
- Variables and built-in types
- Operators, strings, input/output
- Boolean logic and if/elif/else
- for and while loops
- Functions, parameters, return values, scope
- Debugging and readable naming

## Daily plan
1. Set up Python and your editor; run a script from Terminal.
2. Practice variables, types, strings, input, and conversion.
3. Solve small conditional problems using Boolean logic.
4. Practice loops and safely handle bad numeric input.
5. Refactor repeated logic into named functions.
6. Build the guessing game and manually test edge cases.
7. Write a README, review the code without copying, and record remaining questions.

## Weekly build
Create a command-line number-guessing game. The program picks a number, gives high/low hints, counts attempts, rejects invalid input, and ends clearly.

## Testing and evaluation
- [ ] A correct guess ends the game.
- [ ] High/low hints are accurate.
- [ ] Unexpected text input does not crash the game.
- [ ] The loop has a safe exit condition.

Record the commands actually run and observed output. If a check is manual, record the input and what happened.

## Interview / self-explanation questions
- How is a variable different from a value or data type?
- When would you choose a for loop rather than a while loop?
- How does return differ from print?

Answer these in your own words. Revisit any question you cannot explain without notes.

- [ ] Program runs from Terminal using documented steps.
- [ ] At least two useful functions are present.
- [ ] Invalid input is handled intentionally.

A week is completed only after implementation, verification, documentation, and review. Watching videos or generating starter code is not sufficient.
